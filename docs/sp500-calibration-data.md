# S&P 500 для калибровки рынка

Ежедневное закрытие индекса S&P 500 в пунктах, источник S&P Dow Jones Indices
LLC через [FRED SP500](https://fred.stlouisfed.org/series/SP500). Используем ряд
как статистический эталон фондового рынка. Индекс цен не учитывает дивиденды.
Котировок опционов и данных о сделках в ряду нет.

## Воспроизведение

Рабочий снимок получен 28.11.2026 (Europe/Moscow) по
[CSV-запросу за 2017–2025](https://fred.stlouisfed.org/graph/fredgraph.csv?id=SP500&cosd=2017-01-01&coed=2025-12-31).
В корне репозитория:

```bash
uv run python -m finmath.data.sp500 --download \
  --expected-sha256 c953a834947844fadd96daaa6860e862fb16dc8b4952bf77c2456569e7c1bcd2
```

Команда использует `data/raw/fred-sp500.csv`, если он уже существует. С
`--download` она скачивает отсутствующий снимок. Без флага можно указать
локальный файл через `--raw`. Результат сохраняется в
`data/processed/fred-sp500/`. Для повторного прогона укажите новый каталог
`--output`. FRED публикует скользящие десять лет истории. Для точного
воспроизведения после пересмотра или выпадения старых дат нужна локальная
копия с указанным SHA256. Условия FRED требуют разрешения S&P на
воспроизведение ряда. Raw CSV и выгрузки с ценами остаются локально, вне
Git и Kaggle.

## Очистка и покрытие

Дубликаты дат, ошибочные строки, неположительные или неконечные цены и
положительные котировки в выходные приводят к ошибке. Пропуски `.` и пустые
значения исключаются. Скрипт отдельно считает отмеченные пропуски и будни
без строки. Снимок за 2017–2025 содержит 2 347 строк, включая 85 отметок
пропуска. Единственный будний день без строки — 02.01.2017, новогодний
выходной. Сверка дат с `XNYS` в `exchange-calendars==4.13.3` дала 2 262
совпадающие сессии, без пропущенных сессий или лишних закрытий. Эта сверка
выполнена для указанного SHA256, календарь не нужен для запуска скрипта.

Доходность `log(close[t]) − log(close[t−1])` вычисляется между соседними
наблюдаемыми закрытиями. Нерабочим датам не добавляются строки и значения.
Разбиение определяется датой конечного закрытия. У первого закрытия 2017
года доходность пуста. Первая доходность 2023 года использует последнее
закрытие 2022 года как начальное значение и входит только в `holdout.csv`.

Годовая волатильность равна выборочному стандартному отклонению дневных
лог-доходностей, умноженному на `sqrt(252)`. Квантили используют линейную
интерполяцию по упорядоченной выборке. ACF вычисляется в торговых лагах с
общим средним и общей суммой квадратов по выборке, отдельно для `r` и `|r|`.
Полная сводка по обоим периодам записывается в `metadata.json`.

| Период | Закрытия | Доходности | Годовая вол. | p05 / p95 за день | ACF(1) `r` / `abs(r)` |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2017–2022 · калибровка | 1 510 | 1 509 | 20,24% | −1,94% / 1,65% | −0,180 / 0,423 |
| 2023–2025 · отложенная проверка | 752 | 752 | 15,02% | −1,46% / 1,44% | −0,037 / 0,187 |

В #11 параметры подбираются по `calibration.csv`. `holdout.csv` используется
для проверки уже выбранной конфигурации. Положительная ACF модуля доходности
в обоих периодах даёт эмпирический ориентир для кластеризации волатильности.
