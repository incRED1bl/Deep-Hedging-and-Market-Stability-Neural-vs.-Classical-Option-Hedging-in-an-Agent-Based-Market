## 1. Финансовая модель и оценка опционов

В каждом сценарии когорта из 40 хеджеров занимает короткую позицию по европейским
опционам call сроком 20 торговых дней со сдвинутым выпуском (staggered ATM issuance);
покупатель опционов не осуществляет дельта-хеджирование. Базовый режим протокола
использует нулевую ставку фондирования (`r = 0`) и нулевую дивидендную доходность
(`q = 0`), торговый год равен `D = 252` дням.

Для независимого расчёта премий, дельты и переоценки (mark-to-market) незакрытых
опционов применяется классическая модель [Black и Scholes (1973)](https://doi.org/10.1086/260062).
В общем случае при простой годовой ставке фондирования `r_simple` бухгалтерия
использует простую ставку на остаток денежных средств, а в аналитических формулах
Black–Scholes применяется эквивалентная непрерывная ставка
`r = D * ln(1 + r_simple / D)`.

Все четыре исследуемые политики (`bs`, `leland`, `band`, `dl`) получают на момент
закрытия дня `t` идентичное наблюдение — без доступа к будущим ценам и с общей
исторической волатильностью `sigma_t` (выборочное стандартное отклонение последних
20 дневных лог-доходностей, умноженное на `sqrt(252)`, `ddof = 1`, начальное
значение `0,20`, нулевые доходности дней без сделок входят в окно). Политика
выдаёт целевую позицию в акциях, которая передаётся в общий исполнитель с
одинаковыми лимитами заявок и позиций; в портфель попадают только реальные
исполненные сделки (fills) общего пакетного аукциона. Односторонняя комиссия `c`
квантуется до `1e-9` и списывается с каждой стороны каждой сделки.

## 2. Классические стратегии хеджирования

Классические политики служат контрольными ориентирами и позволяют отделить эффект
нейросетевого обучения с учётом риска и комиссий от базовых аналитических и
пороговых правил:

1. **Black–Scholes delta (`bs`):** целевая позиция по короткому call размера `N`
   акций равна `N * Phi(d1)` при `T > 0, sigma > 0`, где
   `d1 = (ln(S / K) + (r + sigma^2 / 2) * T) / (sigma * sqrt(T))`
   ([Black и Scholes, 1973](https://doi.org/10.1086/260062)). Это основной
   компаратор для подтверждающих гипотез.
2. **Поправка Leland (`leland`):** модифицированная волатильность учитывает
   одностороннюю комиссию `c` и ежедневный шаг пересмотра `dt = 1 / D` по формуле
   `sigma_L^2 = sigma^2 + c * sigma * sqrt(8 / (pi * dt))`
   ([Leland, 1985](https://doi.org/10.1111/j.1540-6261.1985.tb02383.x); явная
   конвенция односторонней ставки проверена по §2.1, ур. (5)–(7) в
   [Thai Huu Nguyen и Pergamenshchikov, 2015](https://arxiv.org/abs/1505.02546v1)).
   При `c = 0` стратегия точно совпадает с `bs`.
3. **Delta с областью бездействия (`band`):** вокруг центра `N * delta_BS`
   строится симметричная полоса `[max(0, center - w * N), min(N, center + w * N)]`.
   Если фактическая позиция `shares_held` лежит внутри полосы, цель сохраняет её
   без изменений; снаружи цель проецируется на ближайшую границу полосы
   ([Whalley и Wilmott, 1997](https://doi.org/10.1111/1467-9965.00034); правило
   проекции по §4.1, ур. (12)–(13) в [Imaki et al., 2021](https://arxiv.org/abs/2103.01775v1)).
   Полуширина `w` выбирается отдельно для каждого уровня `c` из фиксированной сетки
   `{0; 0,01; 0,025; 0,05; 0,10; 0,20}` исключительно на validation-эпизодах по
   тому же энтропическому критерию риска (`lambda = 50`, допуск при равенстве `1e-8`
   в пользу меньшего `w`), без подбора по итоговой рыночной волатильности.

Price-taking оптимальность этих стратегий в непрерывном или экзогенном рынке не
переносится автоматически на эндогенный агентный рынок и проверяется только
экспериментально.

## 3. Метрики одного запуска

Каждый запуск `(policy, cost_bps, seed)` сворачивается в одну строку метрик.
Первые `B = 500` дней (burn-in) исключаются из всех наблюдаемых показателей;
шаг `B` фиксирует только опорную цену закрытия `P_500` и начальный капитал
`equity_500`. Наблюдаемое окно состоит из `M = 2 000` последовательных дней
(`t = 501, ..., 2500`).

| Показатель | Определение | Единицы и примечания |
| --- | --- | --- |
| Реализованная волатильность `V` | `sqrt(252) * sample_sd(ln(P_t / P_{t-1}), ddof = 1)` | Доля в годовом выражении; дни без сделок дают `r_t = 0` и сохраняются в ряду |
| Рыночный оборот `U` | `sum(Q_t, t = 501..2500) / 2000` | Акции/день; каждая двусторонняя сделка учитывается один раз |
| Оборот хеджеров `U_hedge` | Среднее за день `sum_h \|actual fills_h\|` | Акции/день; диагностика механизма, не суммируется с `U` |
| Наблюдаемый P&L `net_pnl_observed` | `sum_h (equity_{h,2500} - equity_{h,500})` | Денежные единицы; комиссии, премии, funding, payoff и mark живых call учтены по одному разу |
| Контрактные ошибки (`mean`, `RMSE`, `tail loss`) | По `K` полным контрактам внутри `[500, 2500]`: `epsilon_k = -net_pnl_k / (size_k * issue_spot_k)` | Безразмерная доля номинала (`shortfall > 0`); `tail loss` — среднее `ceil(0,05 * K)` худших ошибок; при `K = 0` значения равны `NA` |
| Диагностики устойчивости | `max_drawdown`, `no_trade_day_share`, `unfilled_hedge_demand_share`, `limit_hit_count`, `negative_equity_days`, `equity_observed_days` | Экономически плохие исходы сохраняются; неполное покрытие `min_equity` помечается как `NA` |

Неполные контракты (выпущенные до `t = 500`, не погашенные к `t = 2500` или
непогашенные) исключаются из расчёта контрактных ошибок, а их число фиксируется
отдельно (`incomplete_contracts_excluded`).

## 4. Гипотезы и статистическая методология

Основная экспериментальная матрица имеет размер `4 политики × 5 комиссий × 50 market seeds`
(`1 000` запусков) при сетке односторонних комиссий
`c ∈ {0; 0,0005; 0,001; 0,002; 0,004}` с базовым уровнем `c0 = 0,001`
(`x = c / c0 = [0; 0,5; 1; 2; 4]`). Внутри одного `market seed` все 20 ячеек
получают идентичное начальное состояние и адресуемые экзогенные шоки.
**Единицей независимого статистического наблюдения выступает `market seed` (`N = 50`),**
а не отдельный торговый день или агент.

Обозначим парные разности на одном `market seed`:
`D_V(s, c) = V(s, dl, c) - V(s, bs, c)` и `D_U(s, c) = U(s, dl, c) - U(s, bs, c)`.
Проциклическая обратная связь short-gamma хеджирования
([Frey и Stremme, 1997](https://doi.org/10.1111/1467-9965.00036);
[Anderegg, Sornette и Ulmann, 2019](https://www.snb.ch/en/publications/research/working-papers/2019/working_paper_2019_03))
в сочетании с cost-aware сокращением ребалансировок
([Bühler et al., 2018](https://arxiv.org/abs/1802.03042v1);
[Imaki et al., 2021](https://arxiv.org/abs/2103.01775v1))
мотивирует единственное подтверждающее семейство из трёх односторонних гипотез
(`alpha = 0,05`):

| Гипотеза | Проверяемый параметр | Альтернатива | Тест и степени свободы |
| --- | --- | --- | --- |
| `H1` (основная) | `theta_V = E_s[D_V(s, c0)]` | `theta_V < 0` | Односторонний парный t-test, `N = 50`, `df = 49` |
| `H2` (вспомогательная) | `theta_U = E_s[D_U(s, c0)]` | `theta_U < 0` | Односторонний парный t-test, `N = 50`, `df = 49` |
| `H3` (вспомогательная) | `beta = E_s[b_s]`, где `b_s = sum_j((x_j - 1,5) * D_V(s, c_j)) / 10` | `beta < 0` | Односторонний t-test по внутрисеменным OLS-наклонам `b_s`, `df = 49` |

Использование внутрисеменного наклона `b_s` с оценкой стандартной ошибки
`SE = sd(b_s) / sqrt(50)` сохраняет зависимость между уровнями комиссии внутри
одного `seed` и исключает занижение стандартных ошибок, свойственное наивной
pooled-регрессии по 250 строкам.

### Множественные проверки, интервалы и диагностика

1. **Контроль FWER:** к трём односторонним `p_raw` применяется пошаговая поправка
   [Holm (1979)](https://www.jstor.org/stable/4615733)
   ([Goeman и Solari, 2010](https://doi.org/10.1214/10-AOS829)). Публикуются
   исходные и скорректированные p-values, статистика, `df`, `N`, эффекты в
   естественных единицах, относительное изменение (`NA` при нулевом среднем `bs`)
   и стандартизованная парная разность `d_z`.
2. **Вырожденные случаи:** при нулевой дисперсии и нулевом эффекте принимается
   `t = 0, p_raw = 1`; при постоянном ненулевом эффекте искусственное `p = 0` не
   присваивается — тест помечается как неоценимый (`p_raw = 1` для Holm, `t-CI = NA`).
3. **Доверительные интервалы:** рядом с оценками приводятся двухсторонние
   **маргинальные 95% t-интервалы** (`coverage_type = "marginal"`), при необходимости
   семейного покрытия — **Bonferroni t-интервалы** уровня `1 - 0,05 / 3`, а также
   **маргинальный 95% percentile bootstrap** по **целым `seed`-блокам**
   (`20 000` повторов, фиксированный `bootstrap_seed = 71001`). В каждом повторе
   пересэмплируются именно целые блоки по 20 ячеек, а не отдельные дни или агенты.
4. **Проверка распределений и sensitivity:** с учётом тяжёлых хвостов рыночных
   доходностей ([Cont, 2001](https://doi.org/10.1080/713665670)) для векторов
   `D_V(c0)`, `D_U(c0)` и `b_s` проверяются квантили, асимметрия, эксцесс, QQ-точки,
   гистограммы, выбросы по `1,5 * IQR` и leave-one-seed-out оценки (включая флаг
   смены знака и расхождения `t-CI` с `bootstrap-CI`). Дополнительно на всех пяти
   уровнях комиссий показываются описательные парные сравнения `DL - BS`,
   `DL - Leland` и `DL - band` по волатильности, обороту, комиссиям, net P&L и
   хеджирующей RMSE.
5. **Полнота матрицы:** финальный анализ (`mode = "final"`) требует точного
   совпадения всех 1 000 ячеек с закреплённым списком из 50 `market seeds`.
   Complete-case фильтрация, удаление убыточных сценариев и изменение гипотез
   после открытия `final-test` не допускаются.

## 5. Границы интерпретации

Снижение реализованной волатильности `V` при падении торговой активности
рассматривается исключительно совместно с долей дней без сделок, просадкой цены,
комиссиями, net P&L и контрактными ошибками хеджирования (`RMSE`, `tail loss`):
остановка торговли или экономия комиссий ценой крупных убытков хеджеров не
трактуется как безусловное улучшение устойчивости рынка.
